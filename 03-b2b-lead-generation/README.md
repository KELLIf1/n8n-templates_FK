# B2B Lead Generation — نظام أتمتة للبحث عن العملاء المحتملين وتصنيفهم

نظام أتمتة يبحث تلقائياً عن عملاء محتملين حسب المجال الجغرافي والتخصص وشروط القبول كعميل محتمل، ثم يستخدم الذكاء الاصطناعي لتصنيف كل عميل وكتابة رسالة تواصل أولى مخصصة له.

## ماذا يفعل النظام؟
- يبحث عن عملاء محتملين حسب المنطقة والتخصص والشروط المحددة
- يصنّف كل عميل بالذكاء الاصطناعي (مؤهل / غير مؤهل مع السبب)
- يكتب رسالة تواصل أولى مخصصة لكل عميل مؤهل
- يسجّل كل شيء في جدول منظم يتتبع تقدم كل مدينة/منطقة على حدة

## النتيجة
توفير ساعات من العمل اليدوي الذي كان يُنجز سابقاً بالبحث والتدقيق واحداً تلو الآخر.

## البنية التقنية (Nodes)
| # | Node | الوظيفة |
|---|------|---------|
| 1 | **Manual Start** | تشغيل يدوي (يمكن استبداله بـ Schedule Trigger) |
| 2 | **Define Search Criteria** | تحديد المناطق، التخصص، الحد الأدنى للتقييم، وشرط وجود موقع إلكتروني |
| 3 | **Split Out Regions** | تفكيك قائمة المناطق إلى عناصر منفصلة |
| 4 | **Loop Over Regions** | معالجة كل منطقة على حدة |
| 5 | **Search Leads (Google Places)** | بحث نصي عن الأعمال حسب التخصص + المنطقة |
| 6 | **Split Out Places** | تفكيك نتائج البحث إلى عناصر منفصلة |
| 7 | **Loop Over Leads** | معالجة كل عميل محتمل على حدة |
| 8 | **Get Place Details** | جلب الهاتف والموقع الإلكتروني والتقييم والعنوان الكامل |
| 9 | **Classify Lead (AI)** | تصنيف العميل (مؤهل/غير مؤهل) حسب المعايير المحددة |
| 10 | **Is Qualified?** | تفرّع حسب نتيجة التصنيف |
| 11 | **Generate Outreach Message (AI)** | كتابة رسالة تواصل أولى مخصصة وغير آلية الطابع |
| 12 | **Log Qualified Lead** | تسجيل العميل ورسالة التواصل في جدول المتابعة، مرتبطاً بمنطقته |
| 13 | **Loop Back (Leads)** | إعادة الحلقة للعميل التالي عند عدم التأهل |

## متطلبات الإعداد قبل الاستخدام
1. مفتاح **Google Places API** (`YOUR_GOOGLE_PLACES_API_KEY`) مع تفعيل Text Search و Place Details.
2. `YOUR_LEADS_SHEET_ID`: معرّف جدول تتبّع العملاء المحتملين في Google Sheets.
3. أضف بيانات اعتماد داخل n8n لـ:
   - **Google Sheets OAuth2**
   - نموذج الذكاء الاصطناعي المستخدم في عقدتي `Classify Lead (AI)` و `Generate Outreach Message (AI)` (أضف عقدة Chat Model متصلة بكل Agent).
4. عدّل قائمة `regions` والتخصص `specialty` وشروط التأهيل في عقدة `Define Search Criteria` حسب السوق المستهدف.

## ملاحظة
حدود استخدام Google Places API قد تتطلب إضافة تأخير (Wait Node) بين الطلبات عند العمل على قوائم كبيرة من المناطق أو العملاء.
