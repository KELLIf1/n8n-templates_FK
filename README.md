# n8n Templates — FK

مجموعة قوالب n8n جاهزة (بصيغة JSON قابلة للاستيراد المباشر) لأنظمة أتمتة حقيقية بُنيت لمتاجر إلكترونية وأعمال B2B، مع شرح تفصيلي لكل قالب وطريقة إعداده.

## القوالب المتوفرة

### 1. [وكيل ذكاء اصطناعي للرد على العملاء (متجر أزياء نسائية)](./01-customer-service-ai-agent)
`n8n · AI Agent · Facebook Messenger · Google Sheets`
يربط Facebook Messenger بوكيل ذكاء اصطناعي يرد تلقائياً على استفسارات المنتجات والمقاسات والأسعار، ويحوّل المحادثة لصاحب المتجر عند الحاجة لتدخل بشري.

### 2. [WhatsApp · تأكيد الطلبات تلقائياً](./02-whatsapp-order-confirmation)
`n8n · WhatsApp Cloud API · Google Sheets · Data Validation`
يقرأ الطلبات الجديدة من جدول البيانات ويرسل رسالة تأكيد تلقائية عبر واتساب، مع التحقق من صحة رقم الهاتف وتحديث حالة الطلب.

### 3. [B2B Lead Generation](./03-b2b-lead-generation)
`n8n · Google Places API · AI Classification`
يبحث عن عملاء محتملين حسب المنطقة والتخصص، يصنّفهم بالذكاء الاصطناعي، ويكتب رسالة تواصل أولى مخصصة لكل عميل مؤهل.

---

## كيفية الاستخدام
1. افتح n8n الخاص بك.
2. من القائمة اختر **Import from File** (أو Import from URL) واختر ملف `.json` الخاص بالقالب المطلوب.
3. اقرأ ملف `README.md` داخل مجلد كل قالب لمعرفة المتغيرات وبيانات الاعتماد (Credentials) الواجب ضبطها قبل التفعيل.
4. اربط بيانات الاعتماد الخاصة بك (Google Sheets، Facebook/WhatsApp، مزوّد الذكاء الاصطناعي...) ثم فعّل الووركفلو.

> **تنبيه:** هذه القوالب تحتوي على قيم عامة (placeholders) مثل `YOUR_PAGE_ACCESS_TOKEN` أو `YOUR_ORDERS_SHEET_ID` — يجب استبدالها ببيانات حسابك قبل التشغيل.

## عن هذا المستودع
هذه القوالب جزء من أعمال أتمتة (n8n) وتطوير تطبيقات (Flutter) تم بناؤها لعملاء حقيقيين، أُعيدت هيكلتها هنا كأمثلة مرجعية قابلة لإعادة الاستخدام والتخصيص.
