# WhatsApp · أتمتة الطلبات — تأكيد الطلبات تلقائياً عبر واتساب

نظام أتمتة يقرأ الطلبات الجديدة المسجلة في جدول البيانات، ويرسل تلقائياً رسالة تأكيد للعميل عبر واتساب باستخدام رقم هاتفه المسجل.

## ماذا يفعل النظام؟
- يقرأ الطلبات الجديدة من جدول البيانات (حالة = "جديد")
- يتحقق من صحة تنسيق رقم الهاتف ويوحّد صيغته الدولية
- يرسل تفاصيل الطلب للعميل للتأكيد عبر واتساب (WhatsApp Business/Cloud API)
- يحدّث حالة الطلب في الجدول (مؤكد / بانتظار الرد / خطأ في رقم الهاتف)

## النتيجة
تقليل نسبة الطلبات الملغاة أو الوهمية، ومنح العميل ثقة إضافية بجدية المتجر.

## البنية التقنية (Nodes)
| # | Node | الوظيفة |
|---|------|---------|
| 1 | **Every 10 Minutes** | مشغّل مجدوَل (Schedule Trigger) |
| 2 | **Get New Orders** | يقرأ من Google Sheets الصفوف التي حالتها "جديد" |
| 3 | **Loop Over Orders** | يعالج الطلبات واحداً تلو الآخر (Split In Batches) |
| 4 | **Validate & Format Phone** | كود JS يوحّد تنسيق الرقم إلى الصيغة الدولية (+213...) ويتحقق من صحته |
| 5 | **Phone Valid?** | تفرّع حسب صحة الرقم |
| 6 | **Send WhatsApp Confirmation** | يرسل رسالة قالب (Template Message) عبر WhatsApp Cloud API |
| 7 | **Update Status: Sent** | يحدّث الحالة إلى "بانتظار الرد" |
| 8 | **Update Status: Invalid Phone** | يحدّث الحالة إلى "خطأ في رقم الهاتف" للمراجعة اليدوية |

## متطلبات الإعداد قبل الاستخدام
1. حساب **WhatsApp Business Platform (Meta Cloud API)** مع رقم هاتف مُفعّل، أو بديل مثل Twilio (يتطلب تعديل عقدة الـ HTTP Request).
2. استبدل القيم التالية داخل ملف الـ JSON:
   - `YOUR_PHONE_NUMBER_ID`: معرّف رقم الهاتف في WhatsApp Cloud API.
   - `YOUR_ORDERS_SHEET_ID`: معرّف جدول الطلبات في Google Sheets.
   - اسم قالب الرسالة `order_confirmation` يجب أن يكون قالباً معتمَداً مسبقاً من Meta.
3. أضف بيانات اعتماد داخل n8n لـ:
   - **Google Sheets OAuth2**
   - **HTTP Header Auth** يحمل التوكن الخاص بـ WhatsApp Cloud API (`Authorization: Bearer ...`).
4. عدّل كود تنسيق رقم الهاتف في عقدة `Validate & Format Phone` حسب الدولة المستهدفة (مضبوط افتراضياً على الجزائر +213).

## ملاحظة
هذا الووركفلو مصمم للعمل مع الجزء الأول (`01-customer-service-ai-agent`) كجزء من نظام متكامل: الطلبات المسجَّلة من وكيل الماسنجر تُقرأ هنا وتُؤكَّد عبر واتساب.
