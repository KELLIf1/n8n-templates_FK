# وكيل ذكاء اصطناعي للرد على العملاء (متجر أزياء نسائية)

نظام أتمتة كامل يربط **Facebook Messenger** بوكيل ذكاء اصطناعي، يرد تلقائياً على استفسارات العملاء حول المنتجات والمقاسات والأسعار، ويسحب بيانات المخزون مباشرة من جدول بيانات محدّث.

## ماذا يفعل النظام؟
- يجيب على استفسارات المنتجات والمقاسات والأسعار فوراً
- يسحب حالة المخزون مباشرة من جدول بيانات (Google Sheets) محدّث
- يتابع حالة كل طلب تلقائياً ويجمع معلومات الطلبية
- يسجّل الطلبات في قاعدة بيانات (Google Sheets) للتواصل مع الزبون لاحقاً وتأكيدها
- يحوّل المحادثة إلى صاحب المتجر عند الحاجة لتدخل بشري (التفاوض أو الشكاوى)

## النتيجة
رد فوري على العملاء على مدار الساعة دون الحاجة إلى موظف دعم إضافي.
هذا الجزء الأول من نظام متكامل يشمل أيضاً تأكيد الطلبات عبر واتساب (انظر مجلد `02-whatsapp-order-confirmation`).

## البنية التقنية (Nodes)
| # | Node | الوظيفة |
|---|------|---------|
| 1 | **Facebook Webhook** | يستقبل أحداث Messenger + طلب التحقق من Meta |
| 2 | **Is Verification Request?** | يميّز بين طلب التحقق الأولي (GET) ورسائل العملاء (POST) |
| 3 | **Respond With Challenge** | يرد بـ `hub.challenge` أثناء إعداد الـ Webhook في Meta |
| 4 | **Extract Message Data** | يستخرج معرف المرسل ونص الرسالة والوقت |
| 5 | **Get Inventory (Google Sheets)** | يقرأ بيانات المنتجات/المقاسات/الأسعار/المخزون |
| 6 | **AI Sales Agent** | وكيل AI (LangChain Agent) يرد على العميل بالاستناد لبيانات المخزون |
| 7 | **Needs Human Handoff?** | يكتشف كلمات مثل "تخفيض"، "شكوى"، "استرجاع" |
| 8 | **Notify Store Owner** | يرسل تنبيهاً لصاحب المتجر عبر Messenger عند الحاجة لتدخل بشري |
| 9 | **Send AI Reply to Customer** | يرسل رد الوكيل للعميل عبر Facebook Graph API |
| 10 | **Log Order (Google Sheets)** | يسجّل المحادثة/الطلب في جدول المتابعة |
| 11 | **Respond OK** | يرد بـ `200 EVENT_RECEIVED` لإغلاق الطلب من جهة Meta |

## متطلبات الإعداد قبل الاستخدام
1. **Facebook Page + App**: أنشئ تطبيق Meta for Developers، فعّل منتج Messenger، واربطه بصفحتك.
2. استبدل القيم التالية داخل ملف الـ JSON:
   - `YOUR_FB_VERIFY_TOKEN`: رمز التحقق الذي تضعه في إعدادات الـ Webhook في Meta.
   - `YOUR_PAGE_ACCESS_TOKEN`: Page Access Token الخاص بصفحتك.
   - `OWNER_PSID`: معرّف صاحب المتجر على Messenger لاستقبال تنبيهات التدخل البشري.
   - `YOUR_INVENTORY_SHEET_ID` و `YOUR_ORDERS_SHEET_ID`: معرّفات جداول Google Sheets الخاصة بك.
3. أضف بيانات اعتماد (Credentials) داخل n8n لـ:
   - **Google Sheets OAuth2**
   - نموذج الذكاء الاصطناعي المستخدم في عقدة `AI Sales Agent` (مثل OpenAI Chat Model) — أضف عقدة "Chat Model" متصلة بالـ Agent قبل التفعيل.
4. اربط رابط الـ Webhook الظاهر في n8n بإعدادات Messenger Webhook في تطبيق Meta.

## ملاحظة
هذا القالب مبني كأساس قابل للتخصيص: أسماء الأعمدة في Google Sheets، صياغة رسائل الوكيل، وشروط التحويل للتدخل البشري يجب تعديلها حسب طبيعة كل متجر.
